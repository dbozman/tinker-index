# ADR 0001 — Use NestJS 12 instead of NestJS 11

- **Status:** Accepted
- **Date:** 2026-11-15
- **Milestone:** M1

## Context

[`architecture.md`](../architecture.md) lists NestJS 11 as the preferred backend baseline. NestJS 12 shipped in August 2026 and became the actively developed major line. NestJS 11 remains on security-oriented support only.

Architecture version policy requires verifying currently supported stable releases and not installing older majors solely because they appear in the reference stack table.

## Decision

Use **NestJS 12** (`@nestjs/common`, `@nestjs/core`, `@nestjs/platform-express`, CLI, testing) for `apps/api` and `apps/worker`.

## Consequences

- Aligns with Nest’s actively supported major version.
- Requires documenting the intentional deviation from the architecture table.
- `@nestjs/schematics@12` currently peers on TypeScript >= 6; the monorepo remains on TypeScript 5.9 for Angular 21 (see [`versions.md`](../versions.md)).
