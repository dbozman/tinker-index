Built for makers choosing their next build

Tinker Index helps you discover DIY projects across electronics, woodworking, 3D printing, robotics, CNC machining, and home improvement.

We surface original analysis and clear project facts—difficulty, estimated cost, build time, and tools—so you can find work that fits your shop and schedule. Every featured build credits the makers and sources who published it.

Catalog browsing, project detail pages, and richer search arrive in the next public website milestone. For now, start on the homepage and explore featured projects.
